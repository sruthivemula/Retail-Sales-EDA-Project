# Retail Sales Data Analysis Project

This project was completed as part of the Oasis Infobyte Data Analytics Internship.

## Objective:
To analyze retail sales data and identify:
- Product category performance
- Customer purchasing behavior
- Gender-wise sales patterns
- Monthly sales trends
- Customer age distribution

## Tools Used:
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Findings:
- Identified top-performing product categories
- Analyzed customer demographics
- Studied monthly sales patterns
- Generated business recommendations

## Conclusion:
This project provides valuable insights for improving sales strategies and customer targeting.
